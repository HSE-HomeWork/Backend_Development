# Backend Avito

## ID - 320671

## Установка и запуск

Установить зависимости проекта:

```bash
uv sync --locked
```

Запустить сервер в режиме разработки:

```bash
uv run fastapi dev app/main.py
```

После запуска документация будет доступна по адресу:

- Swagger UI: <http://127.0.0.1:8000/docs>

## Тестирование

Запустить тесты:

```bash
uv run pytest
```
